# Veille Chine / Philippines

Dépôt de la veille (carte interactive).

- `data/donnees.json` : événements et articles affichés sur la carte (validés).
- `data/a_valider.json` : propositions du script, à relire avant de les passer dans `donnees.json`.
- `scripts/` : script de collecte (étape 3).
- `.github/workflows/` : exécution quotidienne automatique (étape 4).

Étape 1 : dépôt créé avec les données actuelles (31 événements, 37 articles au 22 nov. 2026).
